# Dr. Sabir Ali Siddique — Academic Website

This is a professional, GitHub Pages-ready academic website package for **Dr. Sabir Ali Siddique**.

## Files included

- `index.html` — full responsive academic website
- `404.html` — clean fallback page
- `site.webmanifest` — basic web app/site metadata
- `assets/css/styles.css` — premium dark/light responsive styling
- `assets/js/script.js` — navigation, theme toggle, scroll progress, publication filtering, quick command palette
- `assets/docs/Siddique_Sabir_Ali_CV.pdf` — downloadable CV
- `assets/docs/Sabir_Ali_Siddique_Publications.pdf` — downloadable publications dossier

## Main sections / tabs

Home, About, Research, Projects, Publications, Experience, Awards, Teaching & Skills, CV, Contact.

## Best way to publish on GitHub Pages

1. Create a public repository named exactly:

   `DrSabirSiddique.github.io`

2. Upload the **contents** of this folder directly to the repository root. Do not upload the ZIP itself.

3. Confirm that `index.html` is visible in the main/root level of the repository.

4. Open:

   `https://DrSabirSiddique.github.io`

## Editing essentials

- To replace the initials avatar with a real photo, add your image to `assets/images/profile.jpg`, then edit the profile card in `index.html`.
- To add a new publication, copy one `<li class="pub-item"> ... </li>` block and update year, title, authors, journal and DOI.
- To update CV/publication PDFs, replace the PDF files in `assets/docs/` using the same filenames.
- To change the default color theme, edit the CSS variables at the top of `assets/css/styles.css`.
